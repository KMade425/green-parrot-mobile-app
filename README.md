# Green Parrot Mobile App

A cross-platform mobile content app built with **Ionic and Angular (TypeScript)**. It lets readers browse posts by category, open a post's details, and discover related posts.

## Screens
- **Home:** latest posts feed
- **Categories / View Category:** browse posts by topic
- **Post Detail:** full post view
- **Related:** related-post suggestions

## Tech stack
Ionic · Angular · TypeScript · Cordova (Android/iOS builds) · SCSS

## Run locally
```bash
npm install
npx ionic serve        # run in the browser
```
